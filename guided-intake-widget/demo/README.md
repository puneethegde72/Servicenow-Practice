# Guided intake frontend preview

An interactive, code-rendered illustration of the [guided intake Service Portal widget](https://github.com/puneethegde72/Servicenow-Practice/tree/main/guided-intake-widget). It uses sample data and does not connect to ServiceNow or submit a real request.

Run locally with `npm install` and `npm run dev`. The initial state opens page two to show the difference between overall page progress (25%) and the current page's answered-question ring (50%). Use **Start over** to begin with an empty form.

The actual ServiceNow widget source is in the parent directory. This React app is a visual and interaction preview for sharing the design, not a substitute for the widget code or an update set.
